# T8142 / M5 Hibiscus support

The `main` branch keeps tested upstream base
`9cbde5c7d993844bf086318974958b11076600a0` and adds the `avd-fw-v5-t2`
variant for T8142. This is the project's open-source Cortex-M3 firmware,
with generic Hibiscus register tunables and interrupt masks. It contains
no Apple firmware image, disassembly, raw ADT or per-machine calibration.

The v5 tier-2 path applies flow credits, decode, wrapper, PIODMA, MCW and
AXI2AF tunables in the required order, uses a 0x12000 code/SRAM window and
keeps reserved NVIC lines disabled. Install the built `avd-fw-v5-t2.bin` as
`apple/avd-fw-v5-t2.bin` for the companion
[Linux driver](https://github.com/dmitzsaz/linux).

On J704 / T8142, tested H.264, HEVC 8/10-bit, VP9 and AV1 decode output
matched FFmpeg, including 1080p clips. The driver also needs its T8142
H.264 motion-vector allocation change and a matching boot-time DT/handoff.
All seven firmware variants were rebuilt with Clang/LLD before publication.
Follow the existing Meson cross-build instructions. On a macOS build host,
put `--target=arm-none-eabi` in the cross file's compiler command and select
`c_ld = 'lld'` so Meson does not choose the host Mach-O linker.
